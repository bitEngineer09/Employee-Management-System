🧑‍💼 Employee Management System (EMS)

A full-stack Employee Management System built to manage employees, departments, attendance, leaves, and payroll with role-based access control.
This project is designed to simulate a real-world HR management system used in organizations.

🚀 Features
👑 Admin Features

1.Create, update & deactivate employees
2.Manage departments & roles
3.View employee attendance & leave requests
4.Approve / reject leave applications
5.Dashboard with stats (Active Employees, Attendance, etc.)

👨‍💻 Employee Features

1.Secure login & logout
2.View personal profile & department info
3.Apply for leaves & track leave status
4.View attendance history
